مدیریت کاتالوگ

پاک‌سازی، افزودن دسته‌ها و ورود محصولات کانال از یک صفحه.

مدیریت دسته‌ها مدیریت محصولات
این صفحه فقط برای محیط توسعه یا تست است. قبل از حذف، از دیتابیس و فایل‌های تصاویر backup بگیرید. سفارش‌ها حذف نمی‌شوند، اما محصولات و تصاویر کاتالوگ حذف خواهند شد.

افزودن دسته‌های canonical

فایل هشت دستهٔ اصلی و ۴۹ زیردسته را وارد می‌کند. دسته‌های موجود دوباره ساخته نمی‌شوند.

ورود محصولات کانال

manifest بازبینی‌شدهٔ محصولات کانال را وارد می‌کند و تصاویر را از مسیر تنظیم‌شده می‌خواند.

حذف محصولات

همه محصولات و تصاویر محصول را حذف می‌کند. دسته‌ها و سفارش‌ها باقی می‌مانند.

حذف دسته‌ها

همه دسته‌ها و تصاویر دسته را حذف می‌کند. برای جلوگیری از خطای ارتباطی، ابتدا محصولات را حذف کنید.
